Biz Forecaster - 소상공인 AI 수요예측 프로그램 사용 설명서


1. 실행 방법

  이 폴더의 실행하기.bat을 더블클릭하면 됨.

  - 첫 실행은 필요한 프로그램을 자동 설치하느라 10~30분 걸림. 창을 닫지 말고 기다릴 것.
  - 두 번째부터는 바로 실행됨.
  - 검은 창이 뜨고 잠시 후 브라우저가 자동으로 열림.


2. Python이 없다는 오류가 나올 때

  아래 주소에서 Python 3.11을 설치함.
  https://www.python.org/downloads/release/python-3119/

  설치 화면 맨 아래의 "Add python.exe to PATH"를 반드시 체크하고 설치할 것.
  최신 버전(3.13, 3.14)은 일부 라이브러리 설치가 실패하므로 3.11을 권장함.


3. 처음 사용할 때

  1) 브라우저가 열리면 회원가입 탭을 누름.
  2) 매장 이름, 이메일, 비밀번호를 입력하고 인증코드 받기를 누름.
  3) 6자리 인증코드를 입력하면 가입 완료.
  4) 로그인 탭에서 로그인함.

  이메일 발송 설정이 없으면 인증코드가 메일 대신 화면에 바로 표시됨. 설정 없이도 사용 가능함.


4. 데이터 넣기

  왼쪽 사이드바에서 아래 CSV 파일을 올림.
  양식은 사이드바의 "입력 양식 내려받기"에서 받을 수 있음.

  - products.csv  : 제품명, 판매가, 원가, 회수가, 평소 생산량 (처음 1회)
  - recipe.csv    : 제품 1개당 주요 재료량 (처음 1회, 재료 2~5개면 충분)
  - purchases.csv : 날짜, 재료, 수량 (매입장부 과거분을 한 번에)
  - daily_log.csv : 날짜, 제품, 결과, 생산량 (매일 마감 때)
  - events.csv    : 날짜, 태그 (holiday, rain, event 중 선택. 없어도 됨)

  daily_log.csv 결과 칸 입력 방법
  - 3     : 3개 남음
  - 15:30 : 15시 30분에 품절
  - 0     : 마감 무렵 다 팔림
  - 빈칸  : 입력 안 함
  - 생산량 칸은 평소와 다르게 만든 날만 입력함.

  products.csv 하나만 있어도 예측이 되고, 나머지가 쌓일수록 정확해짐.
  파일이 없으면 "동봉된 예시 데이터로 둘러보기"를 체크해 화면을 둘러볼 수 있음.

  올린 파일은 내 계정 폴더에 보관되어 다음 접속 때 다시 올리지 않아도 됨.
  daily_log.csv는 새 파일을 올리면 덮어씀.

  영업시간, 시간대별 판매 비중 같은 계산 설정은 환경 변수 탭에서 바꾸고 저장할 수 있음.


5. 계정 관리

  로그인 후 왼쪽의 계정 설정 버튼을 누르면 아래 항목을 바꿀 수 있음.

  - 매장 이름 변경
  - 비밀번호 변경 (현재 비밀번호 확인 필요)
  - 이메일(아이디) 변경 (새 주소로 받은 인증코드 확인 필요)
  - 회원 탈퇴

  탈퇴하면 올린 데이터까지 모두 지워지며 되돌릴 수 없음.


6. 종료하기

  검은 창에서 Ctrl + C를 누르거나 창을 닫으면 종료됨.


7. 이메일로 인증코드를 받고 싶을 때

  프로그램 폴더의 secrets.toml.example을 참고해 .streamlit 폴더 안에 secrets.toml 파일을 만들면 됨.
  네이버 또는 구글(Gmail) 계정을 쓸 수 있으며, 일반 비밀번호가 아니라 앱 비밀번호를 발급받아야 함.


문제가 생기면 검은 창에 나온 메시지를 캡처해 개발자에게 전달할 것.
