=====================================================
  Biz Forecaster - 소상공인 AI 수요예측 프로그램
  사용 설명서
=====================================================

[ 1. 실행 방법 ]

  이 폴더에 있는  실행하기.bat  을 더블클릭하세요.
  그게 전부입니다.

  * 처음 실행할 때는 필요한 프로그램을 자동으로 설치하느라
    10분 ~ 30분 정도 걸립니다. 창을 닫지 말고 기다려 주세요.
  * 두 번째부터는 바로 실행됩니다.
  * 검은 창이 뜨고 잠시 후 인터넷 브라우저가 자동으로 열립니다.


[ 2. Python 이 없다는 오류가 나올 때 ]

  아래 주소에서 Python 3.11 을 설치해 주세요.
    https://www.python.org/downloads/release/python-3119/

  설치 화면 맨 아래의
    [v] Add python.exe to PATH
  체크박스를 반드시 켜고 설치해야 합니다.

  ※ 최신 버전(3.13 / 3.14)에서는 일부 라이브러리 설치가
     실패합니다. 3.11 을 권장합니다.


[ 3. 처음 사용할 때 ]

  1) 브라우저가 열리면 [회원가입] 탭을 누릅니다.
  2) 매장 이름 / 이메일 / 비밀번호를 입력하고
     [인증코드 받기] 를 누릅니다.
  3) 6자리 인증코드를 입력하면 가입이 완료됩니다.
  4) [로그인] 탭에서 로그인합니다.

  ※ 이메일 발송 설정을 하지 않은 상태에서는
     인증코드가 메일 대신 화면에 바로 표시됩니다.
     설정 없이도 그대로 사용하실 수 있습니다.


[ 4. 데이터 넣기 ]

  왼쪽 사이드바에서 판매내역 CSV 파일을 올립니다.
  파일이 없으면 "동봉된 예시 데이터로 둘러보기" 를
  체크하면 예시 데이터로 화면을 둘러볼 수 있습니다.

  올린 파일은 내 계정 폴더에만 저장되며,
  다음에 접속할 때 다시 올리지 않아도 됩니다.


[ 5. 계정 관리 ]

  로그인한 뒤 왼쪽의 [계정 설정] 버튼을 누르면
  아래를 바꿀 수 있습니다.

    - 매장 이름 변경
    - 비밀번호 변경 (현재 비밀번호 확인 필요)
    - 이메일(아이디) 변경 (새 주소로 인증코드를 받아 확인)
    - 회원 탈퇴

  ※ 탈퇴하면 올린 매출 데이터까지 모두 지워집니다.
     되돌릴 수 없으니 신중히 결정해 주세요.


[ 6. 종료하기 ]

  검은 창에서 Ctrl + C 를 누르거나 창을 닫으면 종료됩니다.


[ 7. 이메일로 인증코드를 받고 싶을 때 ]

  .streamlit 폴더 안의  secrets.toml.example  파일을 열어
  안내대로 secrets.toml 파일을 만들면 됩니다.
  네이버 또는 구글(Gmail) 계정을 쓸 수 있으며,
  일반 비밀번호가 아니라 "앱 비밀번호" 를 발급받아야 합니다.
